# Changelog

## 1.0.0 - 2026-09-15

- Established Bluewater Scripts as a Python 3.12+ deterministic repository-governance CLI.
- Added schema-validated project-owned configuration and repository profile detection.
- Added changed-scope and full-scope governance execution with stable process exit codes.
- Added Python, PHP, JavaScript, structured-file, Markdown, generated-artifact, and version checks.
- Added thin packaged Git hook adapters and cross-platform GitHub Actions CI.
- Integrated LocaleGuard as the pinned documentation-governance dependency rather than duplicating localization policy.
- Added wheel content verification and isolated installed-wheel consumer verification.
- Added deterministic machine-readable diagnostic output for CI automation.
- Added fail-closed configuration, runtime, integration, and release-validation behavior.

## 1.0.0-dev - 2026-09-10

- Rebuilt Bluewater Scripts as a Python 3.12+ repository-governance CLI.
- Added deterministic configuration validation and repository profile detection.
- Added thin Git hook adapters and cross-platform GitHub Actions CI.
- Integrated LocaleGuard as an immutable documentation-governance dependency.
- Replaced the legacy copied-script architecture with a single canonical execution model.
